# Release Stage Reviews

This directory stores repo-tracked stage-review artifacts generated by
`pnpm review:rc`.

Use it like this:

- current RC-to-`1.0.0` review artifact:
  [2026-09-01-main-rc.md](./2026-09-01-main-rc.md)
- historical beta-era RC review artifacts:
  [2026-08-27-main-rc.md](./2026-08-27-main-rc.md)
  [2026-08-30-main-rc.md](./2026-08-30-main-rc.md)

Interpretation:

- the `2026-09-01` artifact reflects the current `rc` stage and the current
  `rc -> 1.0.0` review contract
- the two August artifacts are preserved as historical evidence from the
  earlier `beta -> rc` decision window; they are not the current review
  template

For the current release gate itself, start with
[../11-npm-release-gate.md](../11-npm-release-gate.md).
