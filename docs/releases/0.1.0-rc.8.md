## Summary

- This RC keeps the same zkSync-native execution baseline, but it sharpens
  the product shell and the release gate around it. The release adds a
  product-style Agent Pay workspace, promotes a packaged `relay baseline`
  surface for remote-browser recovery, tightens the public first-run copy
  around `start` / `next` / `setup` / `pay`, and hardens packaged release
  validation so the gate spends its time in real smoke coverage instead of
  regex backtracking.

## Highlights

- Agent Pay now has a public `workspace` surface that packages dashboard,
  queue, report, and feed into one cross-request workbench, and the root
  help, `payment`, `suite`, docs, and recommended-command contracts now route
  through that surface consistently.
- Hosted approval now has a product-style `relay baseline` surface with one
  support-level summary, proof paths for wallet create and reapprove, and
  rehearsal commands for the operated hosted baseline instead of forcing
  users directly into lower-level relay inspection first.
- `start`, `next`, and `setup` now reinforce one shorter first-run story:
  get through `setup -> next -> wallet create -> next -> pay` once before
  opening broader product surfaces, and only use hosted approval when the
  browser is actually remote.
- Packaged release validation is tighter and easier to trust: release-check
  now emits stage progress, the operator JSON contract gate is aligned with
  the current docs, and the worst pre-pack regex hotspots were removed.

## Known Limits

- This is still an `rc`, not `1.0.0`.
- Hosted approval remains the documented single-host operated baseline; this
  release does not claim a managed or multi-tenant relay service.
- Agent Pay now has a stronger local workbench surface, but it is still not a
  hosted control plane or multi-tenant payment platform.
- Broader DeFi expansion remains deferred; this release focuses on product
  shell clarity, hosted recovery packaging, and release maturity.
