## Summary

- This release publishes the current zkSync-native beta baseline as a usable
  npm package with local-first wallet/session management, hosted relay-backed
  approval, and the flagship `workflow pay` operator path on `sed-lite`.

## Highlights

- The packaged CLI is now a real public surface, not just a source-checkout
  wrapper: global install, one-shot `npx`, packaged help, bundled connector
  UI, and built-in smart-account profile artifacts are all part of the shipped
  contract.
- Hosted approval moved from an implicit prototype assumption toward an
  explicit product boundary. The repo now documents the currently supportable
  operated mode as a single-host, local-filesystem, same-origin hosted relay
  baseline.
- The operator path was tightened around one canonical first-run sequence:
  `setup -> next -> wallet create/reapprove -> next -> workflow pay`, with
  shared `onboardingSummary` and `workflowEntrySummary` JSON contracts across
  the main CLI entrypoints.
- Release validation is materially stronger than the earlier beta cuts.
  `release:check` now verifies packaged install behavior, hosted relay
  readiness, version/doc alignment, and the stable onboarding/runtime JSON
  contracts instead of relying on manual spot checks alone.

## Known Limits

- This release remains `beta`. It should not be presented as `rc` or `1.0.0`.
- Hosted approval is supportable today only on the documented operated
  baseline: one relay process, one host, one persistent local filesystem view,
  and the connector UI served from the same public origin.
- Broader DeFi breadth, broader ecosystem integrations, and additional
  post-flagship product slices remain backlog items rather than part of the
  shipped public promise for this cut.
