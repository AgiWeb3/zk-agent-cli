## Summary

- This RC sharpens the public product shell around the existing zkSync-native
  execution core. The release makes the first-run story shorter, pushes remote
  approval more clearly into fallback territory, and turns Agent Pay plus
  `suite` into easier-to-demo packaged surfaces instead of a collection of
  operator-only entrypoints. The result is not new protocol breadth; it is a
  cleaner, more competitive product surface for the capabilities that already
  exist.

## Highlights

- README, package README, top-level help, `next`, `doctor`, and the repo skill
  now align on one tighter default path:
  `setup -> next -> wallet create|reapprove -> next -> workflow pay`, with
  hosted relay approval framed explicitly as the remote-browser fallback.
- Agent Pay now has a clearer public proof route across
  `submit -> next -> approval -> dashboard -> handoff -> feed`, and `suite`
  exposes that route as structured product guidance instead of leaving it only
  in prose.
- The packaged `suite` contract now carries a bounded optional `proofPath` on
  entries that have a stable public demo route, starting with the Agent Pay
  slice.
- Public wording across help, docs, and JSON contracts now consistently uses
  product-facing language such as dashboard summary, integration-ready bundle,
  and request parties model instead of leaking more internal control-plane
  terminology.
- Release validation was tightened again so the packaged surface, release
  docs, and installed CLI assertions stay synchronized at publish time.

## Known Limits

- This is still an `rc`, not `1.0.0`.
- Hosted approval remains the documented single-host operated baseline; this
  release does not claim a multi-tenant relay or managed hosted service.
- Agent Pay is still a local-first request and follow-up layer. The new
  integration-ready feed and handoff contracts improve packaging, but they are
  not yet a hosted payment platform API or persistence backend.
- Broad DeFi expansion, public identity/reputation, and Polygon-specific
  vertical parity remain intentionally out of scope for this RC.
