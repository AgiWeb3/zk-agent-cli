## Summary

- This beta closes the machine-checkable RC baseline for `zk-agent-cli`:
  hosted approval evidence is now ingestible through `validate:rc`, the final
  beta-to-rc judgment can be written as a repo-tracked review artifact, and
  the host-side release gate is more stable under relay- and listener-heavy
  test load.

## Highlights

- `pnpm validate:rc` now accepts saved hosted-operated-baseline evidence
  automatically from `~/.zk-agent/reports/hosted-operated-baseline/`, and can
  also pin one exact report with `--report-file <path>`.
- `pnpm review:rc` now turns the remaining `beta -> rc` human judgment into a
  repo-tracked markdown artifact instead of leaving that decision only in
  terminal output.
- Hosted relay productization is tighter: the repo now keeps one explicit
  repeated operated-baseline rehearsal path, one deterministic hosted-recovery
  rehearsal path, and one saved RC review artifact for the real public relay
  target.
- Host-side validation is more stable because the relay/await-local timeout
  hotspots that were too tight at `5000ms` were raised to a consistent
  production-grade test tolerance.

## Known Limits

- This release remains `beta`; it should not be presented as `rc` or `1.0.0`.
- `validate:rc` and `review:rc` close the machine gate and record the
  remaining judgment, but they still do not auto-promote the public release
  stage.
- Hosted approval is still supportable only on the documented operated
  baseline: one relay process, one host, one persistent local filesystem view,
  and the connector UI served from the same public origin.
- Broader DeFi breadth remains deferred; the public promise is still centered
  on the local-first wallet lifecycle, hosted approval, discovery, and the
  flagship `workflow pay` path.
