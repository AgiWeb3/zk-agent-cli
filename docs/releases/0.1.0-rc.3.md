## Summary

- This RC finishes another product-shell tightening pass instead of expanding
  breadth. `suite` now reads more like a packaged operator surface with
  explicit journeys and deeper-surface handoffs, `doctor` can now hand off
  cleanly into `suite` when local readiness is already clear, and the packed
  release gate now checks that ready-state contract instead of only the first-
  run path.

## Highlights

- `suite` now exposes stable top-level `journeys[]` and `surfaces[]` metadata,
  so operators and calling harnesses can choose the post-flagship path either
  by operator question or by the deeper surface that owns it next.
- `doctor`, `next`, `wallet status|next`, and workflow follow-up surfaces now
  align on `suiteHandoffSummary`, including the concrete `send-value-now`
  journey hint when the wallet is already ready for the flagship path.
- Root docs, package docs, quickstart, and the main skill guide now say the
  same thing about `doctor -> next -> suite`, which reduces front-door drift
  between public docs, help text, and structured runtime output.
- The packed release gate now validates `doctor --json` in both setup and
  wallet-ready states, including `suiteAvailable`, `recommendedCommands.suite`,
  and the stable `recommendedJourney` handoff.
