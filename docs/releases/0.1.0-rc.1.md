## Summary

- This RC focuses on product-shell cleanup and release discipline rather than
  new chain breadth. The public docs are now shorter and more consistent, the
  operator suite is easier to discover after the flagship pay path, and the
  release tooling is aligned with the current `rc` contract instead of older
  beta-era assumptions.

## Highlights

- Root docs, package docs, and skill docs were compressed into a cleaner
  public shell so users land on one canonical onboarding path faster.
- `release:check`, `sync-release-version`, and the release-script tests were
  aligned with the current `rc` release contract, including current dist-tag
  expectations and current help/doc structure.
- `next`, `doctor`, relay help, and operator-suite surfaces were kept aligned
  so the packaged CLI, repo docs, and machine-checked release gate agree on
  the default path.
- The relay-backed remote-approval runtime smoke now treats `wallet status` as
  a best-effort post-check instead of making the whole approval loop fail on
  transient RPC detection issues after the wallet has already been imported.

## Known Limits

- This remains an `rc`, not `1.0.0`.
- Hosted approval is still scoped to the documented single-host operated
  baseline.
- Broad DeFi route expansion remains deferred; the public promise is still the
  local-first wallet lifecycle, hosted approval, operator-suite readiness, and
  flagship `workflow pay`.
