## Summary

- This RC pushes Agent Pay from a basic local payment-request primitive toward
  a usable operator platform surface. The release adds explicit approval,
  ingress, intent, quote, execution, settlement, queue, lifecycle, inspection,
  and next-step modules inside `packages/agent-pay`, and the CLI now exposes
  richer payment queue/report output with wallet-aware next actions. The net
  effect is a cleaner domain boundary for the future Agent Pay platform and a
  more actionable operator contract in the current local-first product.

## Highlights

- `packages/agent-pay` now has explicit domain modules for approval,
  descriptor, ingress, intent, quote, execution, settlement, lifecycle,
  inspection, queue, and next-step shaping instead of concentrating those
  responsibilities only inside the service layer.
- `zk-agent payment queue` is now a first-class operator surface, so stored
  payment requests can be reviewed as a queue instead of only by one-off
  request inspection.
- Payment reports now include `nextAction`, `routeKind`,
  `countsByNextAction`, and `countsByRouteKind`, which makes the machine and
  human output more useful for triage and operational follow-up.
- The operator JSON contract and architecture docs now describe the expanded
  Agent Pay surface, including how the current local-first CLI maps to the
  future platform layer.
- RC review evidence for the hosted-operated baseline is now checked into
  `docs/release-stage-reviews/2026-09-11-main-rc.md`, so the current RC state
  has an explicit review artifact instead of only transient command output.

## Known Limits

- This remains an `rc`, not `1.0.0`.
- Agent Pay is still a local-first operator surface, not yet a hosted payment
  platform API, multi-tenant control plane, or reconciliation backend.
- The queue/report contract is stronger, but the broad DeFi roadmap and wider
  settlement integrations are still intentionally deferred.
- Hosted approval remains scoped to the documented operated baseline; broader
  relay or hosted-service guarantees are still out of scope for this release.
