## Summary

- This RC tightens the public product shell around the current zk-agent-cli
  contract instead of expanding feature breadth. The onboarding docs, CLI
  help, runtime guidance, and release gates now describe the same operator
  path more consistently, and the release workflow has a shorter repo-tracked
  checklist for repeated cuts.

## Highlights

- Root docs, package docs, quickstart, and the main routing skill were
  compressed into a cleaner English-first front door with clearer handoff
  boundaries between the repo README, package manual, quickstart, and hosted
  approval docs.
- `suite`, `next`, `wallet`, and `workflow` now use a more consistent
  packaged-surface contract across help text, structured output, README copy,
  and targeted regression coverage.
- The release gate now matches the current documentation contract instead of
  older wording assumptions, and `release:checklist` gives a shorter operator
  runbook for version prep, RC evidence, and npm publish.
- Targeted product-surface regression scripts now exist for onboarding, suite,
  and wallet-status flows so repeated RC checks do not depend on hand-typed
  test commands.
